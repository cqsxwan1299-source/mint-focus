# Mint Focus · 薄荷时光

淡蓝与薄荷绿的个人番茄钟，无依赖、无需构建。

## 使用
直接用浏览器打开 index.html。也可以将仓库通过 GitHub Pages 发布（Settings → Pages → Deploy from a branch → main / root）。

## 功能
- 专注 / 休息模式，默认 25 / 5 分钟
- 开始、暂停、继续、结束；结束重置本轮
- 自定义 1–180 分钟，切换中断前会确认
- 按本机日期保存每日待办，支持完成、删除；使用 localStorage
- 基于结束时间校正倒计时，返回后台标签时更新显示
- 响应式布局，所有资源在本地，无外部请求

## 限制
关闭或刷新页面会重置计时。浏览器关闭时不会提醒；后台显示刷新可能被浏览器节流。待办仅存于当前浏览器，建议通过固定 HTTP 地址访问以保持一致存储。

## 开发
原生 HTML / CSS / JavaScript，编辑 index.html 即可。背景由 CSS 渐变绘制。
